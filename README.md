# AI Response Evaluation & Rubric Review
### A Case Study Using AdmitEase AI

**Live Case Study:** [Explore the project website](https://admitease-evaluation.lovable.app)

**Original Chatbot Prototype:** [Visit Westbridge University Admissions Assistant](https://westbridge-uni.netlify.app/)

## Project Overview

This project examines how different prompting and knowledge-base approaches influence the quality of AI-generated responses.

Using AdmitEase AI, an admissions enquiry assistant prototype for a fictional university called Westbridge University, I tested three approaches with Claude and evaluated the responses against a structured scoring rubric.

The project also involved reviewing the evaluation rubric, refining its scoring descriptions, comparing results across the three runs and documenting the findings.

## Project Objectives

- Evaluate AI-generated responses for accuracy and quality.
- Compare different prompting and context approaches.
- Develop and review a structured evaluation rubric.
- Identify strengths, weaknesses and inconsistencies in AI responses.
- Document findings and recommendations.

## Testing Approaches

The evaluation consisted of three runs, with 10 questions and responses in each run.

| Run | Approach |
|---|---|
| Run 1 | Baseline prompting without a knowledge base. |
| Run 2 | Improved prompting with detailed instructions and university information included in the prompt. |
| Run 3 | Claude Project with a structured knowledge base and separate project instructions. |

**Total responses evaluated: 30**

## Evaluation Criteria

Each response was assessed using five criteria:

1. **Factual Accuracy** – Whether the response provided correct and supported information.
2. **Instruction Following** – Whether it followed the given instructions.
3. **Relevance** – Whether it addressed the question appropriately.
4. **Completeness** – Whether it provided sufficient information.
5. **Uncertainty Handling** – Whether it acknowledged missing or unverified information appropriately.

Each criterion was scored on a four-point scale:

- 1 – Poor
- 2 – Below Expectations
- 3 – Good
- 4 – Excellent

The maximum score per response was 20 points.

## Results and Comparison

| Testing Run | Average Score |
|---|---:|
| Run 1 – Baseline | 14.8/20 |
| Run 2 – Improved Prompt | 20/20 |
| Run 3 – Claude Project | 19.1/20 |

Run 2 achieved the highest average score, while Run 3 also performed strongly. Run 1 showed more noticeable weaknesses, particularly in factual accuracy and completeness.

The results provided an opportunity to examine how the structure of prompts and the availability of organised reference information can affect response quality.

## Rubric Review

Beyond evaluating the AI responses, I reviewed the scoring rubric itself to assess whether its criteria and descriptions were sufficiently clear and consistent.

The review led to more specific scoring descriptions for each criterion, helping make the evaluation process more structured.

## Key Learning Outcomes

Through this project, I gained practical experience in:

- AI response evaluation.
- Prompt engineering and context design.
- Rubric development and review.
- Critical reading and factual checking.
- Comparative analysis and documentation.
- Identifying unsupported claims and uncertainty in AI-generated responses.

One important takeaway was that a response can sound convincing without being fully accurate or adequately supported. Evaluating AI output requires careful review, not just accepting the answer at face value.
